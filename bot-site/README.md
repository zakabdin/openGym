# openGym bot site

Next.js (App Router) landing page and PDF workout builder for the openGym Telegram bot.

```bash
cp .env.example .env.local   # set the bot username and public URL
npm install
npm run dev                  # http://localhost:3000
npm run build && npm start
npm run exercises            # regenerate lib/exercises.json from frontend/src/lib/exercises-data.js
```

- `/en`, `/ru` — info, features, FAQ (JSON-LD), link to the bot; `/` redirects by Accept-Language
- hreflang alternates, per-language metadata, sitemap and Open Graph image for both languages (`lib/i18n.js` holds all copy)
- `/builder` — generates a plan in the browser and exports a PDF (no server, no dependencies)
- `sitemap.xml`, `robots.txt`, Open Graph image are generated by Next.

Exercise pictures are hot-linked from the public dataset the app uses (`NEXT_PUBLIC_IMG_BASE` to change); nothing is redistributed. Set `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_BOT_USERNAME` before building.
